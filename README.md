# Counter

אפליקציית PWA בעברית לניהול תקציב אישי. כל הנתונים נשמרים בדפדפן בלבד, ללא שרת, חשבון משתמש או חיבור לבנק.

**גרסה חיה:** [https://lielbs.github.io/counter-budget/](https://lielbs.github.io/counter-budget/)

## הרצה מקומית

נדרשת סביבת Node.js עדכנית (גרסת LTS מומלצת).

```bash
npm install
npm run dev
```

לבדיקת גרסת production:

```bash
npm run build
npm run preview
```

## פרטיות ואבטחה

- אין שליחה של נתוני תקציב לשירות חיצוני.
- אפשר להפעיל בהגדרות הצפנת AES-GCM עם קוד גישה של 6 ספרות לפחות.
- המפתח נגזר מקוד הגישה באמצעות PBKDF2-SHA-256 עם 250,000 איטרציות ואינו נשמר.
- כשהצפנה פעילה, הנתונים הלא-מוצפנים מוסרים מ-`localStorage` והאפליקציה ננעלת אחרי 5 דקות ללא פעילות.
- אין אפשרות לשחזר קוד שנשכח. מומלץ לייצא גיבוי JSON ולשמור אותו במקום מוגן. קובץ הייצוא עצמו אינו מוצפן.
- ההגנה אינה מחליפה נעילת מערכת הפעלה ופרופיל דפדפן אישי. קוד שרץ באותו origin יכול עקרונית לגשת לנתונים כשהכספת פתוחה.

## פריסה ל-GitHub Pages

1. צרו מאגר GitHub וחברו אותו כ-remote למאגר המקומי.
2. ודאו שיש הרשאת push.
3. הריצו:

```bash
npm run deploy
```

הפקודה בונה את הפרויקט ומפרסמת את תיקיית `dist` לענף `gh-pages`. הניווט מבוסס hash ולכן עובד גם ברענון ישיר. הגדרת `base: './'` מתאימה לכל שם מאגר.

## בדיקות

```bash
npm run lint
npm run build
```

## גיבוי ושחזור

במסך הגדרות ניתן לייצא את כל המידע לקובץ JSON ולייבא אותו מחדש. קובץ הייצוא אינו מוצפן, לכן יש לשמור אותו במקום מוגן. מומלץ ליצור גיבוי לפני איפוס או מעבר מכשיר.
